# 独立图形化安装器

在 pweb 目录执行：

```sh
npm ci
npm run setup
```

打开终端输出的安装链接（包含一次性随机访问令牌）。默认地址是
`http://127.0.0.1:3080`。填写 MySQL、Redis、站点地址、管理员信息，测试连接后开始安装。
安装器是独立 Express 进程，不加载 `app.js`、业务路由、Socket 或业务后台任务。
安装完成后按 Ctrl+C 退出，然后执行 `npm start`。

## 环境与配置

- 默认连接空数据库；勾选创建数据库时，填写的账号需要建库权限。
- 默认生产模式要求 HTTPS 站点地址；业务服务监听 `127.0.0.1:3000`，由反向代理提供 HTTPS。
- 本机 HTTP 测试取消生产模式选项。生产代理设置必须与实际部署匹配。
- Redis 是必填依赖；应用 Redis 与 Session Redis 使用不同数据库编号。
- 生成项目根目录 `.env`，独立生成四个随机密钥，不保存管理员明文密码。
- 安装者确认首个管理员邮箱。初始关闭普通用户邮箱验证；配置 `.env.example` 中的
  SMTP 项并验证邮件功能后，再开启 `AUTH_EMAIL_VERIFICATION_REQUIRED=true`。
- 默认拒绝覆盖已有 `.env`；已有部署请执行正式迁移及独立密码恢复流程。
- 安装模式不自动开放；已有库不会因连接失败而重新进入安装。

可选环境变量：`SETUP_HOST`、`SETUP_PORT`、`SETUP_CONFIG_PATH`。
`SETUP_CONFIG_PATH` 供隔离测试或自定义部署使用；业务服务默认仍读取项目根目录 `.env`。
远程安装优先通过 SSH 隧道访问本机安装端口，访问令牌不要分享。

## 数据库基准

`database/schema.sql` 来自 2026-10-04 生产完整备份的 94 张表，包括旧框架表。
仅保留 CREATE TABLE：字段、默认值、索引、外键、字符集、引擎及注释；没有生产数据、
DROP、USE、生产自增计数或生产迁移记录。管理员、17 项系统菜单、默认租户、四种权限模板
和默认设备策略由安装器创建。字典业务内容由管理员配置，不复制生产数据。

安装完成前逐表比较列清单、服务端规范化 DDL 和外键定义；结构差异会阻止继续。
MariaDB 使用 `utf8` 作为 MySQL `utf8mb3` 的同义名称，其余结构保持原定义。
本机验证环境为 MariaDB 10.4.32；MySQL 8.0.45 尚需在对应环境运行同样测试。

manifest 固定记录该结构快照已涵盖的四项 Prisma 迁移及其校验值，安装器新建迁移记录，
不会把未来新增迁移自动标记为已完成。结构快照更新需重新核对覆盖的迁移。

结构提取工具（仅维护者使用，用户安装不需要生产备份）：

```sh
node setup/extract-schema.js /path/to/backup.sql
```

数据库中另建 `poleis_setup_state` 记录阶段；数据库锁避免跨进程同时安装。
中断后重新输入同一数据库信息继续。管理员和基础数据使用事务创建；若已完成数据创建但
配置保存失败，重新提交相同管理员用户名和邮箱会保留原密码。
已有业务库且没有本安装器状态记录时拒绝安装。完成后拒绝重新初始化。

## 验证

```sh
npm test
node setup/test/local-install.js
```

实际安装测试读取本机现有 `.env` 的 MySQL 连接，仅接受 localhost 地址，创建随机命名的
`poleis_setup_test_*` 测试数据库，不修改配置中原数据库。Redis 可用
`SETUP_TEST_REDIS_URL` 指定测试实例。测试配置写入系统临时目录，不改项目 `.env`。
测试数据库保留供检查，终端打印名称和临时配置位置；测试账号密码随机生成，不用于部署。
覆盖安装接口、94 张表完整结构对比、实际 Web 启动、HTTP 登录与管理员权限、重复/并发保护、
非空库保护和中断恢复。浏览器视觉检查需在本机打开安装链接进行。

本机实际验证结果见 [TEST-RESULTS.md](TEST-RESULTS.md)。
